# DSA Algo Practice (C++)

Data structures and algorithms practice in C++17.

## Setup

- Compiler: MSYS2 UCRT64 `g++` and `gdb` at `C:/msys64/ucrt64/bin`
- VS Code extension: C/C++ (`ms-vscode.cpptools`)

## Usage

Open any `.cpp` file, then:

| Action | Shortcut |
| --- | --- |
| Build | `Ctrl+Shift+B` |
| Build and run | `Ctrl+Shift+P` → *Tasks: Run Task* → **C++: build and run active file** |
| Debug | `F5` |

Binaries go to `build/`, which git ignores. Copy `template.cpp` to start a new problem.
